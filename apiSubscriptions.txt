                Get Payment History

    status: number,
    message: string,
    data: [{
        id: number
        user_id: number
        subscription_id: number
        payment_method_id: number;
        total_amount: number;
        status: string;

Method   → POST
Endpoint → /api/v1/payment/initiate/
Auth     → private
Payload  → {
    subscription_id: number,
    payment_method_id: number,
}
Response → {
    status: number,
    message: string,
    data: {
        payment_url: string
        transaction_uuid: string
    }
}

// Payment callback after user pays
Method   → POST  
Endpoint → /api/v1/payment/verify/
Auth     → private
Payload  → {
    transaction_code: string,
    gateway_type: string;
}
Response → {
    status: number,
    message: string,
    data: {
        id: number
        user_id: number
        subscription_id: number
        payment_method_id: number;
        total_amount: number;
        status: string;
    }
}

Method   → POST
Endpoint → /api/v1/payment/webhook/
Auth     → public (no JWT — eSewa server has no user token)
          but verified by HMAC signature
Payload  → varies per gateway (eSewa sends different fields than Khalti)
Response → { status: 200 }
