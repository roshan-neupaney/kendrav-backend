                Get All Ideas
Method   → GET
Endpoint → /api/v1/workspace/:slug_url/idea/?cursor=string&limit=10&status=string&sort_by=string&start_date=string&end_date&search=string
Auth     → private
Response → {
    status: number,
    message: string,
    data: {
        results: [{
            id: number;
            title: string;
            description: string;
            workspace_id: number;
            created_by: string;
            is_hidden: boolean;
            is_active: true;
            status: string;
            created_at: string;
            updated_at: string;
        }];
        next_cursor: string;
        has_more: boolean;
        limit: number;
    }
}
